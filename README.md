# Elevate Fullstack

Projeto convertido do HTML enviado para **React + Node.js + Express + Tailwind CSS**.

## Como rodar

```bash
npm run install-all
npm run dev
```

Abra:

```txt
http://localhost:5173
```

Backend:

```txt
http://localhost:5000/api/health
```

## Funcionalidades

- Layout fiel ao site Elevate
- React + Tailwind CSS
- Node.js + Express
- Navegação funcional com seção ativa
- Botões de contato abrindo WhatsApp/e-mail
- Serviços e processo com ícones SVG no lugar de emojis
- Links de Instagram e LinkedIn clicáveis
- Menu mobile
